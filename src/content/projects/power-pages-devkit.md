Power Pages DevKit provides developer tooling and utilities for working with Microsoft Power Pages.

## Overview

Power Pages development often requires working across multiple tools and interfaces. This project aims to improve the developer experience by providing utilities, extensions, and workflows that streamline common tasks.

## Goals

- Improve local development workflows
- Provide better tooling for content management
- Streamline deployment and synchronisation processes
- Support modern development practices in the Power Platform ecosystem

## Status

Power Pages DevKit is under active development. The scope and features are evolving based on real-world usage and feedback.

## Technology

The project is built primarily with TypeScript and integrates with VS Code and the Power Platform CLI.
